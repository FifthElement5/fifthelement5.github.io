BudzetApp: Web Application


Web Application


This full-stack web application was developed as a university project to streamline budget tracking.


It operates on a Client-Server architecture, combining a Java backend with an interactive web interface to manage and analyze financial data in real-time.


Java

Key Features


Modular Web Interface: A dynamic frontend built to handle CRUD operations for income, expenses, and departments without full page reloads.

Automated Reporting & SMTP: A module that aggregates database records into monthly reports, featuring a direct "Send to Email" function integrated via SMTP.

Notification System: A manual trigger system that allows users to send email reminders for overdue payments directly from the web dashboard.

Spring Security: Secure access control ensuring all management modules are protected by an authentication layer and session management.



View on GitHub

Technical Stack


Backend: Java 17, Spring Boot (Spring Security, Spring Data JPA, JavaMailSender)

Database: MySQL (Relational data persistence)

Frontend: HTML5, CSS3, JavaScript

Environment: IntelliJ IDEA, Maven, MySQL Workbench

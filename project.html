ColorTap: Button-Controlled Ambient Lighting

Technical Overview


Core: ATmega328P (Arduino UNO R3)

Microcontroller: ATmega328P managing real-time LED data protocols.

Input: 3x tactile switches using internal MCU pull-up resistors for mode selection.

Power Design: Dual-rail system – 5V/3A external PSU for LEDs with common ground to the MCU.

Firmware: Custom C++ logic featuring software debouncing and state-machine mode switching.

Display: 60x WS2812B addressable RGB LEDs.


ColorTap is a dedicated hardware controller designed for responsive ambient lighting, powered by the ATmega328P microcontroller on an Arduino UNO R3 platform. The core of the system is a custom firmware implementation that manages a high-speed data stream for 60 addressable WS2812B RGB LEDs.

On the logic side, the ATmega328P handles manual GPIO polling with integrated software debouncing algorithms, eliminating mechanical switch noise.

This allows the state-machine logic to seamlessly transition between power states, static color palettes, and complex dynamic animations without latency or flickering. The result is a robust, MCU-driven lighting solution that demonstrates precise control over addressable LED protocols and embedded system power management

ColorTap: Button-Controlled Ambient Lighting

A hardware ambient lighting controller built on Arduino, featuring real-time LED data streaming and custom embedded C++ control logic.

Technical Overview

Core: Arduino UNO R3 (Development Board)

Microcontroller: ATmega328P managing real-time LED data protocols.

Input: 3x tactile switches using internal MCU pull-up resistors for mode selection.

Power Design: Dual-rail system – 5V/3A external PSU for LEDs with common ground to the MCU.

Firmware: Custom C++ logic featuring software debouncing and state-machine mode switching.

Display: 60x WS2812B addressable RGB LEDs

Technical Core


Microcontroller & Display Powered by the ATmega328P on an Arduino UNO R3 platform, managing real-time LED data protocols. The system drives a high-speed data stream for 60x WS2812B addressable RGB LEDs without latency or flickering.



Firmware Logic

State-Machine & Control Custom C++ logic featuring manual GPIO polling with integrated software debouncing algorithms to eliminate mechanical switch noise. Uses state-machine logic to seamlessly transition between power states, static color palettes, and dynamic animations.

Hardware & Power

Inputs & Dual-Rail Power Features 3x tactile switches using internal MCU pull-up resistors for mode selection. Built on a dual-rail power system utilizing an external 5V/3A PSU for the LED strip, sharing a common ground with the MCU.
